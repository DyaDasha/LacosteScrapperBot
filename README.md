# Lacoste Scrapper bot
## Описание
Я воодушевилась пролистыванием картинок и поэтому решила сделать такого бота

## Возможности
С помощью бота можно просматривать обувь лакосте, при этом выбрав категорию (женская или мужская). После этого можно листать модели назад и вперед. При этом, если модель понравилась, можно перейти на сайт и посмотреть ее

## Функционал
За основу была взята библиотека aiogram. Бот состоит из кнопок, которые находятся под сообщениями. Также я ищу нужную информацию на страницах (цену, модель, картинку) и по нажанию клавиш далее и назад модель отправляется пользователю.
